你要協助使用者開始一個新功能，流程是「確認工作區乾淨 → 建立並切到新分支」。

使用者輸入：`$ARGUMENTS`
- 第一個詞 = **類型**（commit/branch 慣例的 type，例如 `feat`、`fix`、`refactor`、`chore`）
- 其餘 = **描述**（這個功能在做什麼，例如 `會員系統`）

若 `$ARGUMENTS` 為空或缺少描述，請使用者補上後再繼續，不要自行假設。

## 執行步驟

1. **檢查工作區狀態**：執行 `git status --porcelain`。

2. **若工作區不乾淨**（有任何未提交的變更或未追蹤檔案）：
   - 先把目前的變更摘要給使用者看（哪些檔案被改、新增）。
   - 用 AskUserQuestion 詢問要如何處理，至少提供：
     - **Stash**：執行 `git stash push -u`（包含未追蹤檔案），稍後可在新分支用 `git stash pop` 取回。
     - **先 commit**：請使用者說明 commit 訊息，或提醒他自己 commit 後再回來。
     - **不處理，直接帶著變更切分支**：直接 `git switch -c`，未提交的變更會跟著到新分支。
   - 依使用者的選擇執行對應動作後，再進入下一步。
   - 若工作區乾淨，直接進入下一步。

3. **提供三個新分支名稱讓使用者選**：
   - 依「類型 + 描述」推導，格式為 `<類型>/<英文-kebab-slug>`，把中文描述翻成簡潔英文。
     例如 `feat 會員系統` → `feat/member-system`、`feat/membership`、`feat/user-account`。
   - 用 AskUserQuestion 列出三個候選名稱讓使用者選擇（使用者也可自行輸入其他名稱）。

4. **建立並切換分支**：以使用者選定的名稱執行 `git switch -c <branch-name>`。

5. **回報結果**：簡短說明目前所在分支；若先前有 stash，提醒使用者可用 `git stash pop` 取回變更。

## 注意

- 不要在未經使用者確認前就 stash、commit 或丟棄任何變更。
- 分支名稱只用小寫英數與 `-`、`/`，不要有空白或中文。
