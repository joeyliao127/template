2BFF 安全閘道

這是這個 template 最關鍵的設計決策。

🔐 JWT 存在伺服器端

登入後 Spring Boot 簽發的 JWT 由 Nuxt server（BFF）保管，瀏覽器只拿到一個 HttpOnly 的 session cookie，從根本消除 token 被 XSS 竊取的風險。

🚪 單一出入口

前端頁面只呼叫 /api/*；BFF 以 session 找出對應 JWT，附加到往 Spring Boot 的請求上再轉發。瀏覽器永遠看不到後端真實位址與 token。

3後端分層

三層式 ＋ DDD-lite；Service／Repository 皆 interface 對上層、實作在 impl/。資料存取用原生 JDBC（NamedParameterJdbcTemplate），非 JPA。

ControllerREST 端點、參數驗證（@Valid）、錯誤交給 ExceptionHandler 回 ApiResponse
↓
Service應用邏輯；interface + impl/，跨領域可注入其他 Service/Repository
↓
RepositoryJDBC SQL（impl/）＋ RowMapper（rowmapper/）轉成 entity
↓
PostgreSQL原生 SQL，動態過濾用整句靜態 + null-guard

5雙佔位符命名

品牌名常含大寫，但 Docker Compose 專案名與 image repo 強制小寫——因此分成兩個佔位符，/init-template 會各自替換。

佔位符用途範例
__PROJECT_DISPLAY__品牌顯示名（OpenAPI 標題、WEBSITE_NAME、Sidebar、README 標題）YanduoERP
__PROJECT_NAME__小寫機器 slug（Docker Compose 專案名、GHCR image repo、PostgreSQL、域名、cookie）yanduoerp

另：Java package 用真實字 template 佔位（語法不允許 __…__），由 /init-template 一併改名為 com.penguin.<slug>。

6JWT 認證流程

  1. 註冊 POST /api/users/signUp — 建立使用者（密碼 BCrypt）。
  2. 登入 POST /api/users/signIn — 驗證密碼，簽發 JWT；BFF 以 session 保管 JWT、回傳 cookie。
  3. 受保護請求 — JWTAuthenticationFilter 解析 Bearer token → AuthFacade 驗證 token 並確認使用者存在 DB → 放行。

Spring Security 僅做「JWT 有效且 user 存在」驗證，不含 RBAC，保持骨架精簡。

7環境需求

Java 21

後端 pom.xml 設定 java.version=21，內含 Maven Wrapper ./mvnw，免裝全域 Maven。

Node.js ≥ 18 LTS

初始化與 scaffolding 是 .mjs 腳本（init-template、be-entity…），純 Node 內建模組、免 npm install，但需先裝 Node。

Docker / Docker Compose

PostgreSQL、Redis、後端、前端、Nginx 皆以 Compose 運行。

OS

以 macOS / Linux 為主要測試環境；Windows 建議於 WSL 下執行腳本。

mkcert

本機 HTTPS 憑證工具（nginx 需要）。安裝後先執行一次 mkcert -install，把本機 CA 裝進系統信任庫。

8啟動流程

已用 /init-template 初始化的專案 —— Docker/.env 已自動建立並含 JWT_SECRET。

一次性前置（每台機器一次）：安裝 mkcert 後執行 mkcert -install。

  1. 產生本機 HTTPS 憑證（憑證不存在會導致 nginx 啟動失敗；從 ssl 目錄執行才會放到正確位置）
    cd Docker/nginx/ssl && sh generate-ssl.sh && cd -
  2. 設定 hosts（讓網域指向本機）
    echo "127.0.0.1 __PROJECT_NAME__.local.com" | sudo tee -a /etc/hosts
  3. 啟動全部服務
    cd Docker && sh startup.sh
    自動：起 PG/Redis → 等 PG 就緒（首次匯入 schema.sql / data.sql）→ 多階段 build jar → 起 Spring Boot / Nuxt / Nginx
  4. 開啟網站
    前端 https://__PROJECT_NAME__.local.com　·　Swagger http://localhost:8080/swagger-ui/index.html

改完後端 Java 要重新打包：cd BE/SpringBoot && make re（= compose up -d --build springboot）。
